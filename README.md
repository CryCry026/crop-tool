# 裁一下

一款无需安装、完全在浏览器本地运行的图片裁剪工具。

在线地址：https://crycry026.github.io/crop-tool/ 。发布仓库只使用 `CryCry026/crop-tool`，GitHub Pages 来源为 `main` 分支根目录。

“衣格 · 详情页模板工具”独立部署在 https://crycry026.github.io/yige-detail-studio/ ，对应仓库为 `CryCry026/yige-detail-studio`，两个项目不能相互覆盖首页。

## 使用

双击 `index.html`，然后选择、拖入或粘贴一张或多张图片即可开始。

- 拖动裁剪区域内部：移动图片或移动裁框（可在底部切换）
- 拖动绿色控制点：改变裁剪区域
- 比例预设：支持自由、1:1、4:3、3:4、3:2、16:9 和 2:3
- 裁剪比例同步：开启后，当前比例会成为全部待处理图片和后续新导入图片的统一比例；关闭后保留各图当前比例并恢复独立调整
- 边缘吸附：裁剪框或图片靠近对方边缘时自动对齐，并显示绿色参考线
- Photoshop 风格参考线：可添加、拖动、隐藏、清除或双击删除横向/竖向标线；靠近图片中线、图片边缘或裁剪框时自动吸附，并通过绿色线、文字标签和中心菱形提供反馈；参考线不会导出
- 参考线同步：将横竖参考线固定在画布上的相同排版位置，并同步到全部待处理图片；移动、缩放、旋转图片和来回切图都不会改变参考线位置。关闭同步后，每张图片保留当前位置并可继续独立调整
- 批量处理：画布下方显示待处理图片缩略图，可切换或移除，每张图单独保留裁剪设置
- 文件夹导入：Chrome/Edge 中可直接导入一个文件夹（含子文件夹），并为每张图片保留原目录写入权限
- 鼠标滚轮：缩放图片
- 画布旋转：选择“拖动旋转”或底部“旋转”模式后，在画布上左右拖动微调角度；按住 Shift 以 15° 步进
- 单项重置：缩放可单独回到 100%，微调旋转可单独归零，顶部 `0°` 可只重置全部旋转角度
- 方向键：微调图片或裁框；按住 Shift 每次移动 10 像素
- `Ctrl/Cmd + Z`：撤销
- `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y`：重做
- `Enter`：导出图片

支持 PNG、JPG、WebP 导出，可保留透明背景或选择任意背景填充颜色。导出位置提供三种模式：每次选择位置、记住固定默认文件夹、导出到每张原图所在文件夹；跟随原图时还可以选择是否自动建立“裁剪结果”等自定义子文件夹。

JPG 导出支持“限制 JPG 文件大小”：输入每张图片的大小上限（如 2 MB 或 0.5 MB），单张及批量导出都会自动压缩到上限以内。质量滑块作为最高质量；优先降低压缩质量，仍然超限时等比例缩小导出尺寸，不修改裁剪框或原图。导出后显示实际文件大小、采用的质量及是否缩小尺寸。关闭开关即恢复按质量百分比导出，PNG/WebP 不受此开关影响。设置会在当前浏览器中记住。1 MB 按 1,000,000 字节计算，最小上限为 0.001 MB。

普通选择或拖入的图片也可以使用“跟随原图位置”：点击“授权原图文件夹”，选择原图所在目录，工具会核对文件名和文件内容，将原目录关联到已有图片，保留全部裁剪设置。未授权时导出会提示补充授权，批量导出会先检查整批图片；同一文件夹只需授权一次，多个文件夹可逐个授权。无法找到原图时，可选择“本次另选保存位置”，无需重新导入或改变常用导出模式。图片不会上传到服务器。

界面提供青柠绿、冰川蓝、柔光紫和珊瑚橙四种现代主题色，并会记住上次选择。

在“设置”中可以切换普通裁图和固定画布模式。固定画布使用独立于图片的画板尺寸，参考线固定在画板坐标上；每张图片会记住自己的位置、缩放和角度，也可锁定图片以免误操作。图片使用简洁的灰白细线变换框，四角及四条边缘均可拖动并等比例缩放；拖动边缘时固定对边中点，旋转后缩放光标会跟随边缘方向。固定画布不额外描边，图片位置与范围尺寸集中显示在底部状态栏。快捷键可在设置中查看、修改、清除或恢复默认，输入文字时不会触发编辑操作。

固定画布支持尺寸预设：内置 750 × 1000、1200 × 1600、1080 × 1080 和 1080 × 1920，选择后立即应用到整批图片；可一键交换宽高，也可保存、命名和删除自己的常用尺寸。最近使用的 5 种尺寸排在前面，并与自定义预设一起保存在当前浏览器中。切换尺寸保留各图的相对排版；重复应用相同尺寸不会清空图片的撤销记录。

固定画布的每种具体宽高分别记忆参考线：切换尺寸时自动保存当前布局，并恢复目标尺寸上次使用的横竖线。添加、移动、删除、清空及撤销/重做都会更新保存的布局；清空不会在刷新后被旧参考线覆盖。开启参考线同步时，同尺寸的整批图片共用布局；关闭后各图片、各尺寸可独立调整，当前尺寸最后使用的布局仍会记住。横竖交换后的尺寸单独保存；删除常用尺寸不会删除它的参考线，重新使用相同宽高仍可恢复。

首次升级由当前浏览器自动迁移原有已保存的参考线：当前尺寸不变，全部已有基础预设、自定义预设及最近尺寸按画布比例沿用同一初始布局，之后分别记忆。迁移前会将旧设置原文备份到本地存储 `crop-tool-guide-layout-backup-v1`，不上传参考线，也不覆盖已有备份。迁移只执行一次；以后新增的尺寸从空白参考线开始。旧版关闭同步时不会持久保存屏幕上的独立参考线，如需把它们作为初始布局，请在旧页面先开启一次参考线同步再刷新。参考线与预设仅保存在当前浏览器/站点下，清理站点数据或更换浏览器不会自动跟随。普通裁图模式的参考线不受尺寸预设影响。

移动图片以及拖动四边、四角缩放时，都能吸附画布边缘和可见参考线。缩放吸附保持对边或对角锚点固定，临近对齐位置会显示辅助线；继续拖远即可脱离吸附。在设置中关闭“吸附图片边缘和参考线”可自由调整。

默认按 `S` 切换“吸附图片边缘和参考线”，会提示当前开关状态，也可在拖动过程中切换。可在“设置 → 快捷键”中修改或清除这个键位；输入文字、中文输入法组合输入、导出期间或关闭快捷键时不会触发。已有自定义键位会被保留；如果旧键位已占用 `S`，吸附快捷键先显示为“未设置”，可自行指定。
