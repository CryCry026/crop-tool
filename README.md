# 裁一下

一款无需安装、完全在浏览器本地运行的图片裁剪工具。

## 使用

双击 `index.html`，然后选择、拖入或粘贴一张或多张图片即可开始。

- 拖动裁剪区域内部：移动图片或移动裁框（可在底部切换）
- 拖动绿色控制点：改变裁剪区域
- 比例预设：支持自由、1:1、4:3、3:4、3:2、16:9 和 2:3
- 裁剪比例同步：开启后，当前比例会成为全部待处理图片和后续新导入图片的统一比例；关闭后保留各图当前比例并恢复独立调整
- 边缘吸附：裁剪框或图片靠近对方边缘时自动对齐，并显示绿色参考线
- Photoshop 风格参考线：可添加、拖动、隐藏、清除或双击删除横向/竖向标线；靠近图片中线、图片边缘或裁剪框时自动吸附，并通过绿色线、文字标签和中心菱形提供反馈；参考线不会导出
- 参考线同步：将横竖参考线固定在画布上的相同排版位置，并同步到全部待处理图片；移动、缩放、旋转图片和来回切图都不会改变参考线位置。关闭同步后，每张图片保留当前位置并可继续独立调整
- 批量处理：画布下方显示待处理图片缩略图，可切换或移除，每张图单独保留裁剪设置
- 文件夹导入：Chrome/Edge 中可直接导入一个文件夹（含子文件夹），并为每张图片保留原目录写入权限
- 鼠标滚轮：缩放图片
- 画布旋转：选择“拖动旋转”或底部“旋转”模式后，在画布上左右拖动微调角度；按住 Shift 以 15° 步进
- 单项重置：缩放可单独回到 100%，微调旋转可单独归零，顶部 `0°` 可只重置全部旋转角度
- 方向键：微调图片或裁框；按住 Shift 每次移动 10 像素
- `Ctrl/Cmd + Z`：撤销
- `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y`：重做
- `Enter`：导出图片

支持 PNG、JPG、WebP 导出，可保留透明背景或选择任意背景填充颜色。导出位置提供三种模式：每次选择位置、记住固定默认文件夹、导出到每张原图所在文件夹；跟随原图时还可以选择是否自动建立“裁剪结果”等自定义子文件夹。

普通选择或拖入的图片也可以使用“跟随原图位置”：点击“授权原图文件夹”，选择原图所在目录，工具会核对文件名和文件内容，将原目录关联到已有图片，保留全部裁剪设置。未授权时导出会提示补充授权，批量导出会先检查整批图片；同一文件夹只需授权一次，多个文件夹可逐个授权。无法找到原图时，可选择“本次另选保存位置”，无需重新导入或改变常用导出模式。图片不会上传到服务器。

界面提供青柠绿、冰川蓝、柔光紫和珊瑚橙四种现代主题色，并会记住上次选择。
